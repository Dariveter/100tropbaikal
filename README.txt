100 ТРОП — сайт для GitHub Pages
Обновлено 26 октября 2026 года.

В этой версии: галерея впечатлений расположена вертикально без анимации; заголовки разделов и дней программы переписаны.

Публикация:
1. Распакуйте архив.
2. Загрузите index.html, style.css, app.js и папку assets в корень вашего репозитория, заменив предыдущие версии.
3. Добавьте также пустой файл .nojekyll из архива. На Mac скрытые файлы можно показать сочетанием Cmd+Shift+точка. При необходимости создайте .nojekyll прямо на GitHub через Add file → Create new file.
4. В Settings → Pages выберите Source: Deploy from a branch, Branch: main, Folder: / (root), затем Save.
5. Если Pages уже настроен, после сохранения файлов сайт обновится автоматически.

Не загружайте ZIP вместо его содержимого и не вкладывайте index.html в дополнительную папку.

Для просмотра на компьютере откройте index.html. Сборка, сервер и установка зависимостей не нужны.
Все изображения, шрифты и анимации включены в архив.
